# Architecture decision records

Decisions that shape the project beyond a single change. One file per decision, numbered, never rewritten once accepted: a later ADR supersedes an earlier one.

Each ADR states its **status** (Proposed, Accepted, Superseded by NNNN), the **context**, the **decision** with the alternatives rejected and why, and its **consequences**.
